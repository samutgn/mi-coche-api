# Conectar tu coche con Ford

1. Espera a que termine de prepararse el Codespace (la primera vez tarda unos minutos).
2. Abre el terminal (menú ☰ → Terminal → New Terminal) y escribe:

       python herramientas/conectar_ford.py

3. Pega la URL de tu servidor (la que acaba en `.workers.dev`) y la contraseña de la app (APP_KEY).
4. Abre el escritorio: pestaña **PORTS** → puerto **6080** → icono del globo → **Connect** → contraseña `coche`.
5. En ese escritorio verás el login de Ford: entra con tu cuenta de FordPass. La contraseña la escribes tú en la web de Ford.
6. Cuando el terminal diga **¡Conectado!**, ya está. Borra el Codespace en https://github.com/codespaces
